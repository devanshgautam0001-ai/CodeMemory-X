# CodeMemory X Design Tokens

CodeMemory X adapts natively to the active VS Code theme using standardized CSS custom properties.

---

## 🎨 Theme Tokens Matrix

| CSS Variable | VS Code Dark | VS Code Light | High Contrast | Description |
| :--- | :--- | :--- | :--- | :--- |
| `--vscode-editor-background` | `#0f1117` | `#ffffff` | `#000000` | Primary workspace canvas background |
| `--vscode-sideBar-background` | `#161822` | `#f8fafc` | `#000000` | Sidebar navigation rail background |
| `--vscode-editorWidget-background` | `#1a1d2a` | `#f1f5f9` | `#000000` | Elevated glassmorphism card background |
| `--vscode-input-background` | `#13151f` | `#ffffff` | `#000000` | Search and input field background |
| `--vscode-focusBorder` | `#6366f1` | `#4f46e5` | `#f59e0b` | Primary accent focus color (Indigo / Amber) |
| `--vscode-foreground` | `#e2e8f0` | `#0f172a` | `#ffffff` | Primary high-contrast typography |
| `--vscode-descriptionForeground` | `#94a3b8` | `#64748b` | `#d1d5db` | Secondary muted metadata typography |
| `--vscode-button-background` | `#4f46e5` | `#4f46e5` | `#f59e0b` | Primary interactive action buttons |
| `--vscode-errorForeground` | `#f43f5e` | `#e11d48` | `#ff0000` | Risk sentinel and danger warnings |

---

## 📏 Typography & Spacing Scale

* **Font Family:** `var(--vscode-font-family, Inter, system-ui, sans-serif)`
* **Code Font:** `var(--vscode-editor-font-family, JetBrains Mono, Fira Code, monospace)`
* **Radius Tokens:**
  * Base: `0.25rem` (4px)
  * Card: `0.5rem` (8px)
  * Modal: `0.75rem` (12px)
